Azure DevOps CI/CD

Compilación, pruebas y despliegue automatizado directo a Azure App Service.

📌 Endpoints Principales

Ver Swagger Docs →
GET /api/books
Obtiene la lista completa de libros
GET /api/books/{id}
Obtiene el detalle de un libro por su ID
POST /api/books
Crea un nuevo libro en el catálogo
PUT /api/books/{id}
Actualiza la información de un libro
DELETE /api/books/{id}
Elimina un libro validando las reglas de negocio
